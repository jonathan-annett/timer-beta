# Playout computers (experimental)

## Using it (on trial)

On trial on the beta and alpha sites (`features.js`, `TimerFeatures.playout`; the Worker's `FEATURES`): elsewhere `playout.html` isn't served and the timer treats a playout computer as a plain view-only device.

For bigger shows with several operators: an audio operator with the walk-up stings, a video operator feeding the vision mixer, and so on. Each runs `playout.html` on their own computer. It follows the timer's run sheet and plays **their own** audio and video at the moments they choose. The timer doesn't know or control what a playout computer does; it just runs the show.

1. On the playout computer, open `playout.html` next to the timer (e.g. `beta.timed-show.com/p`, short for `beta.timed-show.com/playout.html`).
2. Pair it like an overlay: **share** → **Pair a computer** on the timer, type the 6-digit code on the playout computer, then type the number it shows into the timer's share panel.
3. The timer's run sheet appears. Click **+ cue** on an item and choose when: **At the start**, **When time's up**, **After** m:ss, or **With** m:ss **left**. Then **Choose the sound or video…** opens the same dialog as the run sheet editor's **+ sting**: a stock walk-up sting, a file or a folder of your own (**Custom file**), or one of your clips (**Edited sting**, the sting library). **✂** there makes a clip first.

Whatever you choose is copied into this computer's browser: cues play from here, whatever happens to the site or the network. An AIFF file is copied in as a WAV with exactly the same sound (Chrome and Edge can't play AIFF).

**✂ on a cue** opens the clip editor: just the part to play, fades, a loop and a trim. The file isn't cut. Its loudness is shown against the level of the cue's output (see **Levels** below).

**Levels (loudness normalisation, per output):** every cue's loudness is measured as it plays (LUFS) when it's added, and each output turns its cues down to a level of its own, so one cue isn't louder than the next. **Options → Levels** has a row for **Show** and for each sound card a cue uses: **Level to** −23 LUFS unless changed (broadcast's level; a music service plays at about −14), any level from −40 to −6, or untick it to play that output's cues as recorded (a ✂ trim still applies). Cues are never turned up: one quieter than its output's level plays as recorded, and the row says how many are. **Match the quietest** sets the level to the quietest cue's on that output, so they all play as loud as that one. **▶ Tone** plays the line-up tone (1 kHz) at that level on that output, to set the desk by; it follows the level as you change it, and **■ Tone**, **■ Stop all** or **Esc** stops it. A change applies at once, to cues already playing too. Levels are kept on this computer.

**During the show:** each cue plays once each time its item runs, and plays on into the next items until it ends or you stop it. **Back** on the timer stops whatever is playing here. A playout computer that connects (or reloads) in the middle of an item doesn't replay a cue whose moment has passed, except a start cue within 2 seconds of the start. Time cues count running time: a pause holds them. Several cues at the same moment all play: audio cues together, video cues one at a time (the one lower in the item's list stays on screen).

**Changing a cue:** **✎** changes when it plays (the trigger and its time); **✂** changes the part of the file it plays.

**Your own text for an item:** **✎** on an item (beside its length) opens a box holding its name. Change it, or add notes on the lines under it (Enter starts a new line), then **Save** (or Ctrl+Enter, ⌘+Enter on a Mac). The first line is shown in place of the item's name, in the list and on the status line's *Now*; the rest shows as notes under it. It's kept on this computer only: the timer and every other screen still show the timer's name. Like the cues, it belongs to the item, so it stays when the run sheet is revised. If the timer renames the item afterwards, a line under it says what the timer calls it now, until you open ✎ and **Save** again. Saving the timer's name unchanged, an empty box, or **Use the timer's name** goes back to the timer's. **Cancel** closes the box without changing anything; **Esc** in the box still fades out what's playing (the box stays, with your text).

**Random stings:** **Random stings** under the run sheet works as the run sheet editor's: **🎲 Roll stings** gives every item long enough to be a speaker (2 minutes unless changed) a walk-up sting **At the start**, picked at random, none used twice (a cue you chose counts too), and copied to this computer like any cue. Choose where they come from: the stock stings, a folder of your own, your clips (an edit stands in for the track it came from), and if you like only stings of a certain length. An item with a start cue of your own is left alone. **🎲** on an item picks another for it, keeping when and where the old one played (✎, its output menu); on an item with a start cue of its own it adds one beside it. Rolled cues show 🎲 instead of 🎵. **✂** on one makes it yours, so a roll leaves it alone. Items that have run, the one playing (following the timer) and one you started with ▶ Start item are never rolled. **Remove rolled stings** removes them all; your own cues stay.

**Manual control:** ▶ on any cue plays it now, for testing or by hand. Turn off **Follow the timer** to take over completely (rehearsals, say, where the order depends on who's there): nothing plays by itself and the timer's Back no longer stops anything here; ▶ still works, and **▶ Start item** runs an item's cues as if it had started then: its start cues at once, the others timed from that moment by this computer's clock (*When time's up* and *With … left* from the item's planned length). Starting another item drops the cues the last one hadn't played yet; what's playing plays on. **■ Stop item** stops its cues. While an item's cues play, its **■ Stop item** stays, in green (also once its time is up). If you start another item while one is still playing, the older one's **■ Stop item** flashes green, and so do the **■** of its cues still playing: you're playing more than one item at once. Press it to stop that item (the new one carries on), or leave it to play to its end. While an item runs this way its own cues' ▶ and ■ are locked, so the run stays in charge; **Options → Play and stop single cues of an item started here** frees them at once (for rehearsals). **Fade out** (or **Esc**) fades everything out over 3 seconds; **■ Stop all** stops it at once (and an item started here).

**Output:** video cues play in the **Output** box (one at a time). **Full screen (F)** fills this screen with it, to see how it looks. For the audience's screen, **To external monitor** opens a floating window: drag it to that screen and double-click it (or press **F** in it) for full screen; videos then play there and the Output box says *External playback activated*. **Play here instead** brings them back and leaves the window open and black, ready for next time (not while a video is playing there). Set the window up with nothing playing: while a video plays here and the window isn't open yet, **To external monitor** waits until it stops. Once the window is open, a video playing here moves to it and carries on from where it was (a break of a few frames). If an item you started with **▶ Start item** plays its video here rather than out there, **To external monitor** flashes blue and yellow until you move it or it stops. If the window is closed, videos come back here. After a reload of this page, click **To external monitor** again: it finds the same window. **Sound outputs** (Chrome and Edge) picks the sound card the cues play on and another for the ▶ previews and the clip editor, so you can listen on headphones during the show; if the show's card is unplugged, audio cues don't play (videos play silent) and a warning says so.

**A cue's own output:** the menu on each cue (**→ Show** unless changed) sends that cue to another sound card on this computer, for a cue that needs a channel of its own. A video can have **No sound**: its picture only, so an audio cue starting beside it replaces its soundtrack (the two start together but aren't locked to each other: fine for music, not for lip sync). If a cue's card isn't connected when it's due, it doesn't play (a video plays without its sound) and a note says why; it never goes to another output instead. A cue uses the output its menu shows when it starts; while it plays, the menu is locked (green: in use) until it ends or is stopped. (Changing **Show** in Sound outputs moves what's playing on Show at once.)

**Cues belong to items, not to the pairing:** they stay on this computer when the timer makes a new share code, and an item keeps its cues when the run sheet is revised with **Replace sheet** (rows are matched to the items already there) or edited as a CSV file (its **Id** column). Cues for items that aren't on the timer's run sheet are kept for when they come back; **Remove them** under the list deletes them.

**Connection:** the status line says **⚡ Connected directly** or **Connected via the server**. Either works for playout (the messages are small); via the server, start cues fire after the trip through it. A browser that never connects directly, even next to the timer, may have WebRTC limited: Opera with its VPN sets *Disable non-proxied UDP* (search its settings for WebRTC and choose the default), then reload.

**Demo (no timer needed):** `beta.timed-show.com/p?demo`, or **Try the demo** on the pairing screen, shows the idea without a timer: ten made-up speakers of 20 minutes each, manual only (**Follow the timer** is off and locked), so cues play from **▶ Start item** and ▶. Everything else works as usual: cues, ✂, ✎, outputs, the external monitor. A demo's cues and levels are kept apart from a real show's. The names stay until **New speakers** (the cues stay with their places in the list); **Leave the demo** goes back to pairing.

**Stream Deck (a soundboard):** the **Stream Deck** box gives each item with cues a key, in run sheet order. With **Follow the timer** off (rehearsals, where the order depends on who's there), pressing a key starts its item, as **▶ Start item** does. On an item that's playing (or started here), the key stops it: a tap stops it at once, and holding the key fades it out (over 2 seconds unless changed in the box); let go before the fade ends and it stops right there. The last key does the same for everything (and the line-up tone). When the items don't fit, **◀** and **▶** before it turn the page. With Follow on, the keys show the run sheet (the live item marked **NOW**) and only stop or fade: the timer starts the items. A key shows the item's name as this computer shows it (your text, ✎), its length, and its state: green while playing, amber when started here (with its time), orange while fading.

The same keys are on the page, under the list of decks, and work with the mouse the same way (press and hold to fade), so the soundboard works without a deck too. **On screen** picks the size of deck they're shown as. **Arrange keys** shows every page: drag a key onto another to swap them, or onto an empty key to move it there; **Done** when finished. The arrangement is kept for that size of deck (an XL and an MK.2 each have their own); items added later go at the end, and **Run sheet order** forgets the arrangement.

**Extra keys (media that isn't on the run sheet):** drag audio or video files from your computer onto an empty key of the keys on the page: the key plays that file when pressed (and, playing, a tap stops it and a hold fades it, as an item's), whether you're following the timer or not. Drop several at once and they fill that key and the empty keys after it, in name order. Dropped on an extra key, the new file replaces it (you're asked first); an item's key doesn't take files. The extras are listed under the keys, where ▶ plays one, ✂ trims it and its menu picks its sound card, as for any cue; ✕ removes it and frees its key. On other sizes of deck they come after the items. **+ Page** adds a page of empty keys to drop files on (◀ ▶ then turn the pages), and **− Page** removes the last page once it's empty.

**On a phone:** **Show on a phone…** shows a QR code: scan it with the phone's camera and the same keys open on the phone, as the size of deck shown on the page (the phone's menu changes it). The phone shows a 3-digit number: type it in the box that appears here, and it's in (one wrong try and that phone is out). The code disappears from the screen once a phone has picked it up; **Show the code again** brings it back for another phone. On the phone a tap and a hold work as on a deck, and its screen stays on. A phone let in comes straight back after a reload; **Revoke** takes the keys away from it, **New code** signs every phone out, and **Stop sharing** ends it (phones get the keys back with **Show on a phone…** again). Phones need the playout page open: it hosts them, through the pairing server.

**Which deck is whose:** quit the Elgato Stream Deck app first (it holds every deck), then **Connect a deck…** and choose it: it's used here from then on. Every deck the site may use is listed, with **Use here** or **Give to the timer**. On a computer that runs the timer too, the timer page uses the decks that aren't the playout's, and lets go of one the moment the playout page takes it (and the other way round), so a 15-key deck can run the show from the timer while a 32-key deck is the soundboard. **From the deck itself:** the key next to the last one is **Give to the timer**: it hands that deck back to the timer page. In the timer's deck editor, put **Give deck to playout** (under *Other*) on a key of your layout, and the playout's **Give to the timer** moves to the same key, so that one key hands the deck back and forth. Either key works only while the other page is open in this browser (and the timer's only takes a deck when it hasn't got one), and is dimmed otherwise, so a deck is never handed to nobody. A deck handed back to the timer shows Elgato's screen for a moment, then the timer's keys. This works in one browser, with the timer and the playout from the same site: other browsers, and alpha against beta, can't see each other's choices, so forget the deck there (the timer's deck editor: **Forget deck**). Two decks here each have their own page. Decks are told apart by their serial number (not yet tried on real decks: if two of the same model get mixed up, tell us).
