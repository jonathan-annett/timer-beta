    Built on Transformers.js running LAION's CLAP models (ONNX conversions by Xenova). The model files come from Hugging Face on first use, then the browser caches them. Each clip is resampled to 48 kHz mono and embedded in 10-second windows; the clip's embedding is the normalised mean of its windows. If the page stays on "Starting…" when opened straight from disk, serve the folder instead, for example with python3 -m http.server, and open http://localhost:8000. LAION-CLAP code and weights are released under permissive terms (Apache-2.0 / CC0); check the model cards before shipping.
