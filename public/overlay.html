Timer overlay

A countdown that floats on top of other windows (PowerPoint's Presenter View, say), fed by the timer on another computer.

On the timer, open share and click Pair a computer. Type the 6-digit code it shows:

Pairing server
Connecting…
Shape
The overlay is in its floating window. Drag it where you want it and resize it; closing it brings it back here.
Then minimize this window: the overlay keeps running on top, with no keys needed.

The timer asks who this is. Tell the person at the timer this number (or read it to them over the phone). One wrong try disconnects this computer.
