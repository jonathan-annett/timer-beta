What's new

Changes to the timer, newest first. Back to the timer

Next update

  • A fresh look for the timer screen: the button bar, the times along the bottom and the links now match the run sheet editor and the phone remote (dark outlined buttons, Pause in green, share and deck lit while on). The countdown and the presenter screen are unchanged.
  • Notices with pictures, everywhere: ⏳ Wrap up – last minute, ⏰ Time’s up, ⏸️ Paused · 2:13 and 🎬 Standing by. Phones, displays and overlays now show exactly what the presenter screen shows.
  • Your own words: notices (bottom left) lets you change any of them, for example 🙏 Please wrap up. Every screen follows.
  • Clearer keyboard hints: key caps instead of [brackets], changing as you hold Ctrl or Shift or type a time.
  • Typing a time shows it big: start typing digits (handy with a numeric keypad) and a large panel shows what you typed and the duration it makes. Enter sets it as the default, Space or * starts it, Esc cancels.

30 October 2026

  • Fixed: a phone or display connected while a countdown was running could be out by the time since it started, until the next restart.
  • Run sheet standby: Reset show now readies the first item: its time, dimmed, with its name up and Standing by. on every screen. Next, Resume or Space starts the show.
  • Auto start: give the first item a start time and tick Auto start at hh:mm (dashboard or editor): the screens count down (Standing by to start in 5:23…) and the show starts by itself.
  • The presenter window now shows the pause notice too.
  • Fixed: reloading the timer with a presenter window open could make the countdown jump.
  • Shared screens count down by themselves: phones, displays and overlays work the countdown out locally from the timer's start, pause and adjustments, instead of being sent a new time every second. Same display, far less traffic, especially through the server.
  • Hard starts: tick the box before any start time in the run sheet and that item starts by itself at its time, if it's next; if something before it hasn't run, its row flashes red instead. Ticked times stay put when earlier items change length. Every item has a tick: ticking one whose start you didn't type fixes it at the time it shows.
  • Run sheet mode hides the preset buttons, for a tidier bar: the other buttons stay where they were, with the site's name in the gap.
  • The run sheet editor shows the time of day (to the second) at the top right.
  • Edit the run sheet from a phone or tablet: on a remote's run sheet view, tap ✎ Edit run sheet. The timer asks you to allow it (share panel), and you can Stop editing any time. Remote editors on a computer now ask first too.
  • The run sheet editor has a Clear sheet button above the column of ✕ buttons.
  • Safari: the floating overlay (O) starts again (it said “not triggered by a user activation”).
  • Phone timer: the buttons now read Restart and Pause; while paused, Resume blinks along with the ends at time, so it's clear which one carries on.

29 October 2026

  • Let a friend control your timer with a code. On a phone or tablet, tap ⋯ → Let a friend control this timer: your friend opens /control on this site and types the 6-digit code (or scans a QR code instead). ⋯ → Take back control disconnects them at once.
  • Shorter address: the timer is now just the site's address, nicer to copy and share. Old links still work.
  • Phone timer: a full-screen button, and Bar, Clock and Undo pauses in the ⋯ menu. Bigger details when the phone is on its side; the progress bar sits above the buttons; messages fit the screen upright.
  • Keyboard on a remote: a remote control opened on a computer takes the timer's own shortcuts (durations, Space, pause, arrows, B/M/T…).
  • Virtual Stream Deck: the Backlight key dims the phone's deck along with a real one.
  • Phones that are disconnected or unpaired go back to the code screen, ready to pair again.
