What's new

Changes to the timer, newest first. Back to the timer

Next update

  • Revising the running order: Replace sheet with a new version keeps the items that are already on the sheet (matched by name, in order), with their videos and walk-up stings; their times come from the new version. During the show, rows that have already run are left out.
  • Export CSV adds an Id column: edit the file in a spreadsheet and open it again with Replace sheet, and every item stays itself, even renamed (new rows can leave the Id empty).
  • Walk-up stings from AIFF files (Logic, Pro Tools) now work in Chrome and Edge, which can't play AIFF: the file you choose is turned into a WAV with exactly the same sound as it's added.

11 November 2026: Stream Deck keypad, random stings and sound outputs

  • New default Stream Deck layouts (MK.2 and XL), with the Keypad key; the phone's virtual XL too. A layout you've customised stays as it is: Reset defaults in the deck editor brings the new one in.
  • + sting: a long file name in a folder's list no longer pushes the ▶ and ✂ buttons out of the dialog.
  • Run sheet editor: Back and Next no longer jump when the show starts (a long status is shortened with … instead of pushing the clock onto a second line), and docked, the show's title sits on the editor's top bar, leaving the header more room.
  • Random stings: the run sheet editor's new Random stings panel gives every speaker a walk-up sting picked at random, never the same track twice, from the stock stings, a folder and your clips, with a length filter. 🎲 on a row picks another for that item; stings you chose yourself are left alone.
  • Sound outputs: choose the sound card the show plays on (stings, videos, the line-up tone) and another for previews and editing, e.g. headphones, in the run sheet editor's Options (Chrome and Edge). Audition stings on headphones while the show's play out on the PA; if a chosen output is unplugged, nothing plays there instead of going somewhere else, and a warning says so.
  • Stream Deck keypad, safer for two people: left untouched for a minute it closes and drops the time typed on it (a time typed on the keyboard stays), and Start and Set default do nothing until a time is typed (they used to restart the countdown if the typed time had been cleared, say by someone's Next).
  • The Stream Deck editor opens on top of the docked run sheet (it used to open underneath it).
  • The clock badge shows when you're offline: it turns red and reads offline · clock synced 14:02. The clock is still right, but phones, displays and Companion can't connect until the computer is back online. (A green badge used to look like “online” even with the laptop off its wifi.)
  • A Now key for the Stream Deck: the run sheet item running now, with its length and when it started, beside Back, Next and Schedule (in the deck editor's Run sheet palette). The Back key now names the item it goes back to, as Next does.
  • The Stream Deck's Keypad key is a big 🔢 now.
  • MK.2 keypad: the Cancel key turns into ⌫ while you type, and back into Cancel when it's all deleted, like the keyboard.
  • Phone Stream Deck taps: a tap that moved slightly on a key was ignored; now any tap that ends on (or just beside) the key counts.
  • Start and Pause keys that show the times: Start with the default duration under it; Pause with the countdown above and the pauses below (counting while paused). On the Mini by default, and in the palette for any deck.
  • Stream Deck Mini: its key images were upside down and mirrored; fixed. The deck editor has a Key images menu for any deck whose images look rotated or mirrored.
  • Virtual Stream Decks in three sizes: a phone's deck view can be an XL, MK.2 or Mini (a small phone as a Mini). The deck editor's Use as virtual deck… opens an on-screen deck in its own window, for a touch screen or to try a layout before saving; its ⋯ → Show on a phone puts it on a phone with one scan.
  • Update preset on the XL keypad: type a time, press Update preset, then the preset key it's for (only they show, in blue); any other key goes back to the keypad.
  • Stream Deck keypad: a Keypad key turns a 15- or 32-key deck into a number pad for typing any duration (digits, : and .), with Start, Set default and Cancel; the XL shows the time as you type it, the 15-key deck on its Start and Set default keys.

11 November 2026: your own Stream Deck presets

  • Your own Stream Deck presets: in the deck editor (D), click a preset key and type any duration (25, 1:15, 0:04:30); the key labels itself from it, or takes a label you type. Drag a preset from the palette onto it to put that one back.

11 November 2026: walk-up stings

  • Walk-up stings on beta: give a run sheet item a short piece of music or a video that plays as it starts, cut just the part you want with the clip editor (fades, loops), keep a sting library, and level them all to the same loudness with a line-up tone for the mixer. Until now only on alpha.

11 November 2026, later

  • The clip editor fits the window (sting clips, on trial, alpha only): in a short window (or the docked run sheet editor) it scrolls inside and keeps Save and Cancel on screen; it used to run off the top and bottom.

11 November 2026

  • One tab runs the timer. Open the timer in a second tab and it just shows the countdown, with Use this tab instead to move the timer there. Two tabs used to fight over the countdown (it flickered after a run sheet Reset). If the tab running the timer closes, the other takes over.
  • Bitfocus Companion: the module now has its own home and releases; the share panel's Companion page links to the download. Fixed: that page showed a QR code (of another link) instead of only the link to copy.
  • Slides are gone from the run sheet (on trial, alpha only): the Slides column, Close slides and the PowerPoint computers (receiver page and player) are removed, to come back later in a playout tool. Decks already attached are cleared from the browser.
  • One playing bar for stings and videos: the yellow bar with Fade out and Stop now shows videos and the line-up tone as well as stings, on the timer's screen (on top of the docked run sheet editor) and in the run sheet editor's own window, so a video can be stopped from there too. Esc in the editor fades out as well.
  • Sting levels (on trial, alpha only): stings are measured (LUFS) and turned down to one level, so a quiet one and a loud one sound the same; the clip editor shows the loudness and has a Trim. Options → Sting levels: the house level (−23 LUFS), Level this show… (the quietest sting's level, for the most signal) and a 1 kHz line-up tone at that level for setting the mixer.
  • ✂ in the + sting dialog (on trial, alpha only): beside each list (stock stings, your clips, a folder's files), straight into the clip editor. Save and use keeps the clip in your sting library and puts it on the item; Cancel saves nothing.
  • Stings from a folder (on trial, alpha only): + sting → Custom file → Choose a folder… lists its audio and video files to pick from (Chrome and Edge remember the folder). The link box is gone (few sites let a page copy their files); link stings already on a sheet still play.
  • Esc fades out whatever is playing over 3 seconds: a walk-up sting, or a video, which then ends as if it had finished. With a panel open, Esc closes the panel instead. In Chrome's full screen a tap does it too; hold Esc to leave full screen.
  • delete is Back in run sheet mode, as Space is Next (on the timer and in the run sheet editor), for Mac keyboards without Page Up / Page Down (Fn+↑ / Fn+↓ work too). While you type in a box in the run sheet editor, it turns navy: Space and delete then just type.
  • The run sheet editor opens inside the timer's screen, along the bottom: drag its top edge to resize it, ✕ to close it. ⧉ Own window moves it to a window of its own as before (and it opens there from then on); that window's ⇲ Dock brings it back. A reload keeps your choice.
  • Loops in sting clips (on trial, alpha only): make a short sting longer. In the ✂ editor, Add a loop (or Shift+drag on the track) marks a part to repeat; set how many times it plays, hear it over and over with ▶ Preview loop while you move its edges, check the joins with ▶ Around the loop, and drag its ⟲ tab to put the repeats somewhere else in the track. Too long to keep as a clip? Save as WAV makes the edit a file of its own, to add as the sting's file.
  • Sting clips (on trial, alpha only): the ✂ editor shows a standard 6-second close-up while you work on the start or the end (with First 2 s / Last 2 s to hear them), and the sting dialog now has three tabs: Walk-up sting, Custom file and Edited sting. The sting library opens inside the run sheet editor.
  • Playout computers (on trial, alpha only): another computer pairs with the timer and plays its own audio and video cues as the run sheet moves on: at an item's start, at a time into it, or when its time is up. ▶ plays any cue by hand; Follow the timer off takes over completely.
  • Sting clips (on trial, alpha only): ✂ on a sting opens its waveform: pick just the part to play, with fade in and out, without special software. A Sting library page keeps your clips (of the stock stings or your own tracks) and exports or imports them.
  • Walk-up stings (on trial, alpha only): give a run sheet item a short piece of music or a video, from a stock list, a link or a file, that plays as the item starts while the item keeps its own time. It plays on (under an introduction, then the speaker's countdown) until another sting starts or you fade it from the timer's screen or a Stream Deck key.

10 November 2026

  • Arm presets: click the Presets label in the button bar to make presets (the bar's and the Stream Deck's) only arm the timer: it shows the time, paused and standing by, until you press Space, Resume or the deck's Start key. A yellow badge shows while it's on.
  • Clock badge: the control screen now shows whether the clock is synced to internet time (green), on this computer's own clock (yellow) or corrected by hand (blue). Click it to switch, retry with Sync now, or set the right time yourself. Changing the clock doesn't disturb a running countdown.
  • Messages and run sheet names are kept apart. A message you send (C, a phone, a Stream Deck key, Companion) now shows over the run sheet item's name instead of replacing it, and clearing your message brings the name back. A new item clears the last speaker's message.
  • Quiet mode (Q, a Stream Deck Quiet key, the phone's Quiet button): only the countdown on the presenter's screens, with no message, notice, time of day or bar, until you turn it off or the next item starts. Your own screen keeps them, dimmed, under a QUIET badge.
  • On a phone or tablet, sharing keeps the screen on: a locked screen stops the timer page, and with it the devices following it.
  • A notices button in the button bar turns the last-minute and time's-up notices on and off (M), lit while they're on, in place of the yellow messages enabled line. The words themselves are now under notice words.
  • Shift+click run sheet turns run sheet mode on or off without opening the editor, and the run sheet button is lit whenever run sheet mode is on.
  • Typing seconds: two dots separate minutes from seconds, so 1..30 is a minute and a half and 1:20..25 an hour, 20 minutes and 25 seconds. One dot is still part of a minute (1:30.5 = 1:30:30).
  • Shift+← / → moves the timer by a whole minute, like Ctrl+← / →, which a Mac keeps for switching desktops.
  • Fixed: the run sheet view on phones and displays now shows when the current item actually started (red if late, green if early), not just its planned time.
  • The webcam video assist (V, Shift+V, Ctrl+V, Shift+W) has been removed.
  • Turning run sheet mode off now clears the item’s name from the screen and leaves the timer paused at your own default time (not the last item’s), ready to start.
  • Even G2 glasses: a presenter chooses what shows beside the countdown (your messages by default; the item name and the last-minute notices if they like), and the operator's glasses can turn quiet mode on and off. The operator's Minimal view now sits in a corner, like a presenter's (Next corner in the glasses' menu moves it). A presenter isn't shown Timer offline for a short drop: their countdown carries on, and the notice appears only after a minute (the operator's glasses show it at once). Everything in the glasses' menu is also a button on the app's phone page, and taps can be set never to fire Next.

31 October 2026 (late)

  • Space is Next in run sheet mode, on the timer and in the run sheet editor (unless you've just typed a time, which Space then starts, or you're typing in the editor). A keypad’s * works too. The touch Restart button and a Stream Deck’s Start key still restart.
  • Fixed: typing hours and minutes (1:22) and backspacing past the : closed the box but kept the hours, so the : came back with the next digit.

31 October 2026 (later)

  • Even Realities G2 glasses (beta): the timer on your smart glasses. A presenter sees a small countdown in a corner; the operator sees the operator's screen in miniature and can go Next with a few taps, or Back, Pause, Reset show and Auto start from the glasses' menu. Pair with share → Pair a computer, and choose Presenter or Operator when you let the glasses in. It's in beta testing: contact the developer to be added to the testers. Details in the help, under Even Realities G2 glasses.

31 October 2026

  • A fresh look for the timer screen: the button bar, the times along the bottom and the links now match the run sheet editor and the phone remote (dark outlined buttons, Pause in green, share and deck lit while on). The countdown and the presenter screen are unchanged.
  • Notices with pictures, everywhere: ⏳ Wrap up – last minute, ⏰ Time’s up, ⏸️ Paused · 2:13 and 🎬 Standing by. Phones, displays and overlays now show exactly what the presenter screen shows.
  • Your own words: notices (bottom left) lets you change any of them, for example 🙏 Please wrap up. Every screen follows.
  • Clearer keyboard hints: key caps instead of [brackets], changing as you hold Ctrl or Shift or type a time.
  • Typing a time shows it big: start typing digits (handy with a numeric keypad) and a large panel shows what you typed and the duration it makes. Enter sets it as the default, Space or * starts it, Esc cancels.

30 October 2026

  • Fixed: a phone or display connected while a countdown was running could be out by the time since it started, until the next restart.
  • Run sheet standby: Reset show now readies the first item: its time, dimmed, with its name up and Standing by. on every screen. Next, Resume or Space starts the show.
  • Auto start: give the first item a start time and tick Auto start at hh:mm (dashboard or editor): the screens count down (Standing by to start in 5:23…) and the show starts by itself.
  • The presenter window now shows the pause notice too.
  • Fixed: reloading the timer with a presenter window open could make the countdown jump.
  • Shared screens count down by themselves: phones, displays and overlays work the countdown out locally from the timer's start, pause and adjustments, instead of being sent a new time every second. Same display, far less traffic, especially through the server.
  • Hard starts: tick the box before any start time in the run sheet and that item starts by itself at its time, if it's next; if something before it hasn't run, its row flashes red instead. Ticked times stay put when earlier items change length. Every item has a tick: ticking one whose start you didn't type fixes it at the time it shows.
  • Run sheet mode hides the preset buttons, for a tidier bar: the other buttons stay where they were, with the site's name in the gap.
  • The run sheet editor shows the time of day (to the second) at the top right.
  • Edit the run sheet from a phone or tablet: on a remote's run sheet view, tap ✎ Edit run sheet. The timer asks you to allow it (share panel), and you can Stop editing any time. Remote editors on a computer now ask first too.
  • The run sheet editor has a Clear sheet button above the column of ✕ buttons.
  • Safari: the floating overlay (O) starts again (it said “not triggered by a user activation”).
  • Phone timer: the buttons now read Restart and Pause; while paused, Resume blinks along with the ends at time, so it's clear which one carries on.

29 October 2026

  • Let a friend control your timer with a code. On a phone or tablet, tap ⋯ → Let a friend control this timer: your friend opens /control on this site and types the 6-digit code (or scans a QR code instead). ⋯ → Take back control disconnects them at once.
  • Shorter address: the timer is now just the site's address, nicer to copy and share. Old links still work.
  • Phone timer: a full-screen button, and Bar, Clock and Undo pauses in the ⋯ menu. Bigger details when the phone is on its side; the progress bar sits above the buttons; messages fit the screen upright.
  • Keyboard on a remote: a remote control opened on a computer takes the timer's own shortcuts (durations, Space, pause, arrows, B/M/T…).
  • Virtual Stream Deck: the Backlight key dims the phone's deck along with a real one.
  • Phones that are disconnected or unpaired go back to the code screen, ready to pair again.
